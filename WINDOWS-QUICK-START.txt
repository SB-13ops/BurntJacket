BURNT JACKET — WINDOWS QUICK START

FIRST TIME ONLY
===============

1. Install these three programs:
   - Python 3.11 or newer
   - Node.js LTS
   - Docker Desktop

2. Make sure Docker Desktop is running.

3. Double-click:

       SETUP-BURNTJACKET.bat

   The setup will:
   - create Burnt Jacket environment files
   - start PostgreSQL
   - create the Python virtual environment
   - install backend packages
   - install frontend packages
   - initialize the Burnt Jacket database

4. When setup says complete, close the setup window.


EVERY TIME YOU WANT TO USE BURNT JACKET
===================================

Double-click:

       START-BURNTJACKET.bat

Burnt Jacket will:
- start PostgreSQL
- start the FastAPI backend
- start the Next.js website
- open your browser automatically

Website:
    http://localhost:3000

API documentation:
    http://localhost:8000/docs


TO STOP BURNT JACKET
================

Double-click:

       STOP-BURNTJACKET.bat


OPTIONAL: DISCOGS + CONCERT SCOUT
=================================

Read:

       CONFIGURE-KEYS.txt

Then edit the .env file with your own API credentials.


TROUBLESHOOTING
===============

If START-BURNTJACKET does not work:

1. Confirm Docker Desktop is running.
2. Look at the "Burnt Jacket API" window for backend errors.
3. Look at the "Burnt Jacket Web" window for frontend errors.
4. Re-run SETUP-BURNTJACKET.bat if dependencies were changed.
