BURNT JACKET OPTIONAL API KEYS

Open the file named:

    .env

and fill in the values you want to use.

DISCOGS
-------
DISCOGS_CONSUMER_KEY=
DISCOGS_CONSUMER_SECRET=

Create a Discogs developer application, then paste the values after the "=".

Keep:
DISCOGS_CALLBACK_URL=http://localhost:8000/api/v1/integrations/discogs/callback


TICKETMASTER
------------
TICKETMASTER_API_KEY=

This enables live Concert Scout data.


OPENAI
------
OPENAI_API_KEY=

Not required for the current deterministic V1 Hunter/DNA logic.
It will be used when we add richer natural-language and explanation features.


IMPORTANT
---------
Do not share your API secrets publicly or commit your populated .env file to GitHub.
